# Art Workspace

This folder is for art production files and references.

- `source/`: Original images, PSD files, rough PNGs, and editable source files.
- `generated/`: AI-generated images before cleanup or slicing.
- `sprites/`: Finished PNGs prepared for Godot import.
- `ui/`: UI icons, frames, buttons, and panel art sources.
- `refs/`: Visual references, mood images, and style examples.

Godot runtime assets should live under `assets/`:

- `assets/cards/`
- `assets/enemies/`
- `assets/ui/`
- `assets/backgrounds/`

Use `art/` for work-in-progress and `assets/` for files the game actually loads.
